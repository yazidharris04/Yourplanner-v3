🔐 Login

Buat akun sekali di setiap perangkat dengan username dan password. Password minimal 10 karakter dan harus memuat huruf dan angka. Semakin panjang, semakin aman.

Aplikasi otomatis terkunci setelah 15 menit tidak ada aktivitas.

📱 Pindah ke perangkat lain

Di perangkat pertama, klik Cadangan untuk menyimpan file .json. Di perangkat kedua, buka halaman login, klik Impor cadangan, lalu masuk dengan username dan password yang sama.

Tidak ada sinkron otomatis. Setelah mengubah data di satu perangkat, buat cadangan baru dan impor lagi di perangkat lain.

⚠️ Penting

Kalau password lupa, data tidak bisa dipulihkan. Simpan file cadangan di tempat yang aman dan jangan bagikan ke orang lain.
